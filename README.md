# Buxola Norme

Assistente normativo interno alla rete: previdenza, infortuni, disabilità,
successioni e polizze vita. Risponde solo sugli articoli indicizzati e cita
sempre la fonte con la data di vigenza.

Fonte dei testi: Normattiva — Presidenza del Consiglio dei Ministri / IPZS,
CC BY 4.0. I testi non hanno carattere di ufficialità.

## Configurazione
La chiave del modello va messa nei Secrets come `API_KEY`.
